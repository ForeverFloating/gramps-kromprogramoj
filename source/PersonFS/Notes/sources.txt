# *What is the best way to transfer sources entered in Gramps to FS?*  

First difference:
In Gramps, there is a hierarchy repository --> source --> citation 
, nothing like this in FS for manually entered sources: the only equivalent is for citations.

## user-entered FS sources
in FS, manually entered sources have:
  * personal folders to group sources, hidden from other users.
  * sources with the following properties:
    * identifier (service:id)(gedcomx:SourceDescription.id)
    * date (not part of the gedcomx standard!) (service:event.eventDate)(gedcomx:SourceDescription._date (custom addition))
    * title (single-line text) (service:title)(gedcomx:SourceDescription.titles)
    * a URL, or a memory (service:uri[uri])(gedcomx:SourceDescription.about)
    * reference (multiline text) (service:citation)(gedcomx:SourceDescription.citations)
    * note (multiline text) (service:notes)(gedcomx:SourceDescription.notes)
    * Reason for source modification: (multiline text) (service:notesJustification)
  * source references with these properties:
    * source (SourceReference.descriptionId)
    * reference: individual, couple, …
    * tags (SourceReference.tags), the same as a reference
      * for a person reference: name, sex, birth, baptism, death, burial, military service, ….
    * Reason for adding this source: (multiline text)
    note: sources can be referenced by:
      * a person
      * a couple
      * an event

## Gramps sources
In Gramps, there are:
* repositories, which have the following properties:
  * name
  * ID
  * type (library, archive, website, …)
  * addresses
  * Internet links
  * notes
  * references = list of sources that reference it.
* sources, which have the following properties:
  * ID
  * title
  * author
  * publication information (e.g. internet link and/or ISBN and/or publisher, …)
  * abbreviation
  * notes
  * galleries (images)
  * attributes
  * repositories
  * references = list of citations that reference it.
* citations, which have the following properties:
  * source
  * ID
  * date
  * volume/page
  * confidence level
  * notes
  * galleries
  * attributs
  * references = list of people, families, events, media, names, addresses, attributes, … that references it.

## comparaison

The handling of sources between Gramps and FS is very different. Therefore, the interface between the two can only be very partial: a lot of information will be lost bidirectionally.
* major differences:
  * Gramps citations do not have titles!
  * no hierarchy in Gramps repositories.
  * Gramps cannot list people cited in a document.
  * Gramps does not support specifying a primary person.
  * Gramps does not support event types.
  * Gramps does not support place information.
  * Gramps does not provide information at the citation reference level.
  * Gramps supports multiple notes of varying types, but not FS.
  * Gramps supports tags and attributes, but not FS.
* similarities in source management:
  * FS place ~ repository
  * collection: ~ repository, but repository hierarchies are not possible in Gramps…
  * FS digital film folder ~ Gramps source
  * FS document ~ Gramps citation
  * FS source ~ Gramps citation

## unavoidable information loss (to be completed):
* syncing from FS-->gramps for FS documents:
  * loss of nested collections
  * loss of reason for attaching reference.
  * documents and sources are both mapped to a single Gramps citation.
* syncing from FS-->Gramps for user-entered sources:
  * loss of repository and source information.
  * loss of reason for attaching reference.

* syncing from Gramps-->FS:
  * FS lacks repository information (for user-entered sources).
    * repository information must be manually copied into each FS source's reference field.
  * FS does not support films, resulting in source information loss.
    * source information must be manually copied into each FS source and its corresponding reference field.
  * FS allows only one note per source, but Gramps allows multiple notes
    * source and citation notes must be consolidated into a single FS note field.


## Syncing from Gramps --> FS:
### Gramps citation --> FS source  
  * FS title
    reminder: Gramps citations do not have titles. (title displayed for citation = source title)
    a typical title in FS is: main person's name [x spouse's name], event type. place.  
    problem: Gramps does not support main people or main events in citations. No main place either.  
    decision: the first line of the "Citation" type note --> title  
      --> this may result in unusual titles for citations not meant to be transferred.  
      --> this significantly constrains how citations are entered in Gramps…  
  * FS date
    it exists in both systems, but isn't a part of the gedcomx standard, preventing API transfer.  
    Therefore, it must be updated using the service interface (which is undocumented).
  * FS URL
    "Internet Address" attribute --> URL
  * FS note
    decision: the notes will be concatenated:
    * the citation type first, excluding the first line (used for the title)
    * then other notes, each prefixed with its title "***"
  * FS reference
    FS uses this field for the Gramps source equivalent.  
    decision: repository title + source title + volume/page + confidence level --> reference
    * repository title --> line 1 of the reference, prefixed with _('Repository')+_(':')+' '
    * source title --> line 2 of the reference, prefixed with _('Source:')+' '
    * volume/page --> line 3 reference, prefixed wiht _('Volume/Page:')+' '
    * confidence level --> line 4 reference, prefixed with _('Confidence:')+' '
### referencing by a person
  no problem: this functionality exists in both systems.
### referencing by an event
  birth, baptism, death, burial --> link to the corresponding person's reference
  marriage???  
  other???  

preventing duplicates in FS during transfer is critical.
  * since source IDs cannot be transferred directly, a 3-step process is required:
    * creation of the source linked to a person using the API.
    * retrieving its ID.
    * update the date using the service interface.
    * connection to other relevant events/people.

## Syncing from FS source --> Gramps citation:
### example FS source links:
  * API link: https://www.familysearch.org/platform/sources/descriptions/3V5Z-7VR
  * service link: https://www.familysearch.org/service/tree/links/source/3V5Z-7VR
  * UI link: https://www.familysearch.org/tree/sources/viewedit/3V5Z-7VR
  * API reference link: https://www.familysearch.org/platform/tree/source-references?description=S1G1-GPN

### mapping fields:
  * id = SourceReference.descriptionId=SourceDescription.id --> _FSFTID citation attribute
  * date =  servicesource.event[0].eventdate = SourceDescription._date --> citation date
  * web page = SourceDescription.about --> citation URL
  * title (SourceDescription.title) + note up to "***" --> citation note.

### user-defined source from Gramps:
  * reference (SourceDescription.citations):
    * line 1 --> repository title
    * line 2 --> source title
    * line 3 --> volume/page
    * line 4 --> confidence level

### user-defined source of unknown origin:
  * first line of reference --> source title.

### FS source:
  * reference = SourceDescription.citations -->   
      within quotation marks: source title (This is the collection title)  
      following: to be determined ("FamilySearch reference" note type?)  
  * collectionUri = servicesource.fsCollectionUri = source's "Internet Address" attribute, 
    * collection number: source ID, and attribute 
  * "FamilySearch": repository title.
  * film number: attribute?
  * collection number: attribute?
